# GenoLOM Evolution

Research implementation of an evolutionary educational-content framework based on GenoLOM metadata, the Computer Science Ontology (CSO), genetic operators, and content operators.

## Project Status

- Phase 1 — Segmentation, metadata annotation, and CSO classification: Complete
- Phase 2 — Evolutionary backend: In development
- Phase 3 — User interface: Planned

## Repository Structure

- `CSO-Classifier/` — Phase 1 implementation and datasets
- `PDFs/` — Project proposal and reference documents
- `phase2/` — Evolutionary backend (to be added)
